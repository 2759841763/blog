## step3：配置JS-SW的ip地址

### 进入终端

①先右击启动JS-SW

②再右击启动命令行终端

### 配置ip

```
<H3C>sys                                //进入
System View: return to User View with Ctrl+Z.

[H3C]sysn JR-SW                         //这个是重命名系统名字sysname的简写sysn


[JR-SW]int Vlan-interface 1          //int是intface的简写，表示是进入vlan1的端口

[JR-SW-Vlan-interface1]ip address 10.50.1.254 24      //配置
```

**解释：**

所有的配置操作都是要进入命令系统下的，所以先进入命令系统下

提示符从 `<H3C>` 变成 `[H3C]`，代表现在在**系统视图**，可以做全局配置（改名字、vlan、接口、acl 等）H3C

```
sys     /这个是system-view的简写
```

## step4：配置认证连通失败

```
[JR-SW-Vlan-interface1]dot1x     
[JR-SW]int g1/0/1            
[JR-SW-GigabitEthernet1/0/1]dot1x
```

H3C 硬性规则：**全局开 dot1x + 端口下开 dot1x，两个同时开启，这个端口的 802.1X 才生效**

### 解释

```
[JR-SW]dot1x                // 【全局视图】开启整台交换机的802.1X总开关
```

- 作用：打开设备 802.1X 这个功能的总闸门，**只是总开关，所有端口还没启用认证**
- 相当于：交换机支持 802.1X 了，但哪个端口要认证，还要单独在接口下打开

```
[JR-SW]int g1/0/1
[JR-SW-GigabitEthernet1/0/1]dot1x    // 【物理接口视图】在G1/0/1这个端口开启802.1X认证
```

- 作用：单独给这个端口开启准入控制
- 效果：电脑插在 G1/0/1 上，**没输对账号密码之前，不能访问内网、不能上网**，只能收发 802.1X 认证报文；认证成功后端口放行，正常通信H3C

## step5：配置认证用户名密码使用Inode软件认证登录

```
[JR-SW]local-user admin class network    //创建用户admin
[JR-SW-luser-network-yige]password  simple admin123  //创建密码admin123
[JR-SW-luser-network-yige]service-type  lan-access //设置服务类型
```

**service-type lan-access**

- 意思：这个账号只能用来做**以太网局域网接入认证**，也就是 802.1X 认证、MAC 认证H3C
- 不加这条：就算账号密码对，802.1X 也认证失败！交换机不认这个账号是上网账号
